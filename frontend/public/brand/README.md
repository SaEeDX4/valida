2. Maintain aspect ratio.
3. Prefer dark/black backgrounds; transparent variants were mechanically derived from the approved raster and are optimized for dark surfaces.
4. Keep adequate clear space around the mark.
5. Do not use the words or symbol as evidence of a capability, certification, compliance status, or security guarantee.
6. This pack is raster-based. If a true vector SVG master is required later, it should be manually vector-traced from this approved reference and separately approved before replacing these assets.
